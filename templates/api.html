Bulk Certificate Generator

Submit a list of recipients once. Each one gets a personalised PDF certificate.

Checking service…

API

POST /api/v1/jobs Queue a bulk job — returns a job_id immediately
GET /api/v1/jobs/{job_id} Progress: total, completed, failed, pending
GET /api/v1/jobs/{job_id}/certificates Per-recipient result and download URL
GET /api/v1/certificates/{certificate_id} Download one PDF
GET /api/v1/health Readiness
GET /docs Interactive API documentation

Example

curl -X POST http://127.0.0.1:8000/api/v1/jobs \
  -H "Content-Type: application/json" \
  -d '{
    "event_name": "Python Workshop",
    "date": "2026-10-08",
    "recipients": [
      { "name": "Aditya Singh", "email": "aditya@example.com", "course": "CSE" },
      { "name": "Meera Raman", "course": "IT" }
    ]
  }'
{
  "job_id": "job_5f2c9b1e4d7a4c8f9e0b1a2c3d4e5f60",
  "status": "PENDING",
  "total": 2,
  "completed": 0,
  "failed": 0
}
